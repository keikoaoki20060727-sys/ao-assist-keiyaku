# 毎朝の手順：【部署名】（【ファイル名】）

- 動かす時間：毎日【時間】
- 作るもの：【例：朝のまとめ（今日やること3つ）】
- 置き場所：`できあがり/【ファイル名】/YYYY-MM-DD_【内容】.md`

## 定期タスクに登録する文

この枠の中の文だけをコピーして、定期タスクに貼ります。

```
あなたはこのフォルダの会社のNo.2です。CLAUDE.md を読んでから始めて。
1. ループ/【ファイル名】/STOP があれば、何もしないでここで終わる。
2. 【部署名】（.claude/agents/【ファイル名】.md）に、今日の分の【作るもの】の下書きを1本作らせる。材料は 材料/【材料の場所】 だけを使う。
3. できた下書きを 品質チェック係（review）に審査させ、判定を下書きの一番下に書き足す。作り直しはしない。
4. 下書きは できあがり/【ファイル名】/今日の日付_【内容】.md に保存する。
5. 送信・投稿・予約・公開・支払い・カレンダー登録・ファイルの削除はしない。下書き保存まで。
6. うまくいかなかったら、ループ/【ファイル名】/止まった記録.md に「日時／どこで止まったか／理由」を1行書いて終わる。
```
