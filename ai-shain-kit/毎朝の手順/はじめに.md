# 毎朝の手順（ルーティン業務）

「毎朝7時に朝のまとめを作る」のように、決まった時間にAI社員が自分で動く仕事の置き場所です。Claude のデスクトップアプリの **定期タスク** に、1つの文と時間を登録すると動きます。

**最初の1週間は登録しません。** 手で動かして、できあがりに納得してから、1つずつ登録します。

ルーティンでも **「下書きまで」は変わりません。**

---

## 準備

- [ ] 毎日使う部署を、手で3回動かした（「No.2として、【部署名】に今日の分を1回やらせて」）
- [ ] できあがりを読んで、直したい所を部署ファイルの「直したことの記録」に1行足した
- [ ] 登録するのは **1つだけ**。1つ登録したら3日ようすを見てから次へ

## 手順1　登録する文を、Claude に作ってもらう

```
【部署名】（ファイル名：【ファイル名】）の仕事を、毎日【時間】に定期タスクで動かしたい。
毎朝の手順/ひな形.md と同じ形で、毎朝の手順/【ファイル名】.md を作って。
登録する文には、必ず次を入れて：
・最初に ループ/【ファイル名】/STOP があれば何もしないで終わる
・送信・投稿・予約・公開・支払いはしない。下書き保存まで
・うまくいかなかったら ループ/【ファイル名】/止まった記録.md に1行書いて終わる
作る前に中身を見せて、わたしが「OK」と言ったら保存して。定期タスクの登録は、わたしが自分でする。
```

## 手順2　定期タスクに登録する（社長が自分でする）

デスクトップアプリで「定期タスク」の画面を開く →「新しいタスク」→ フォルダは **このキットのフォルダ** を選ぶ → `毎朝の手順/【ファイル名】.md` の「定期タスクに登録する文」の枠の中の文をコピーして貼る → 許可の設定は「毎回確認する」のままにする → 時間を選んで保存

## 手順3　最初の1回は、パソコンの前で「今すぐ実行」

- このフォルダの中のファイル（`.md`・`.csv`）を作る・書きかえる確認なら「許可」
- send・post・publish・schedule・reserve・create_event・delete・remove・pay・purchase の文字が見えたら「拒否」
- 「いつも許可」は押さない
- 意味が分からない確認も「拒否」。あとで Claude に「さっきの確認は何？」と聞けば大丈夫です

## 見るところ

| 見る所 | こうなっていればOK |
| --- | --- |
| `できあがり/【ファイル名】/` | 決めた時間のあとに、新しいファイルが増えている |
| `ループ/【ファイル名】/止まった記録.md` | 空、またはファイルがない |
| メール・LINE・SNS | 何も送られていない（下書きだけ） |

## 止め方

- **少し止める**：「ループ/【ファイル名】/STOP を作って」と頼む（再開は「STOP を消して」）
- **ずっと止める**：定期タスクの画面で、そのタスクをオフにする
- **いま動いている途中**：停止ボタン（■）

同じ止まり方が2回続いたら「ループ/【ファイル名】/止まった記録.md を見て、直し方の案を出して」と頼みます。3回続いたら、タスクをオフにして相談してください。
