# よくある質問

**Q. Notionを使っていません。なくても大丈夫？**
なくても大丈夫です。AI社員はフォルダの中のファイル（`できあがり/` に入る下書き）だけで動きます。

**Q. メルマガの文字化けと、毎回のプロフィールを何とかしたい**
長い文章はチャットからコピーせず「`できあがり/` にファイルで保存して」と頼み、ファイルを開いてコピーします。プロフィールは `プロフィール.md` に保存し、「一字一句変えずに差し込む」とルールに書いておくと、毎回同じ文章が入ります（`CLAUDE.md` の「4. 書き方のルール」に入っています）。

**Q. 部署をあとから増やしたい**
次の文を送ります。
```
部署カタログ.md を読んで、今のわたしの仕事に合う部署を1つ提案して。選んだら .claude/agents/ に作って、CLAUDE.md の部署一覧と No2の役割書.md の振り分け表にも足して。保存の前に中身を見せて。
```

**Q. 部署を減らしたい**
「〇〇部を部署一覧から外して。ファイルは消さずに残して」と頼みます。

**Q. 人間の秘書とAI秘書、どう分ける？**
AI秘書：朝のまとめ・議事録・返信の下書き・請求書の一覧・調べもの。人間の秘書：電話や対面、日程の交渉、気持ちに寄り添う対応、お金やアカウントの操作、ほかの人との調整。

**Q. お客様の名前を入れてしまった／「いつも許可」を押してしまった**
あわてなくて大丈夫です。何を入れたかは書かずに、「入れてしまった」「押してしまった」とだけ、個別に相談してください。

**Q. AIが動き続けていて止めたい**
停止ボタン（■）を押します。

**Q. 確認の画面に curl・install・brew・pip・sudo の文字が出た**
一度「拒否」して相談してください。このキットでは、道具のインストールはしません（`.claude/settings.json` でも止めています）。
