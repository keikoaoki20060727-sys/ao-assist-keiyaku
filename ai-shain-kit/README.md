# AI社員キット（説明書）

Claude（デスクトップアプリの「Code」の画面）に1つの文を送ると、Claudeが1問ずつ質問しながら、あなたの仕事に合ったAI社員（部署）だけをつくります。部署は最初から決まっていません。

あなたは「社長」です。**方針を決める・OKを出す・最後のボタンを押す**、の3つはあなたがします。

---

## 3つの約束（はじめに必ず読む）

1. **メール・LINE・SNS・請求書は下書きまで。** 送信・投稿・公開・支払いのボタンは、あなたが押します
2. **お客様のお名前・会社名・連絡先はAIに入れません。** 入れるときは「Aさん」「A社」「お客様」に置き換えます
3. **確認の画面が出て、読んでも分からなかったら「拒否」で大丈夫です。** send・post・publish・delete・remove・pay・purchase・sudo の文字が見えたら、必ず「拒否」

APIキー・パスワード（英数字の長い合言葉）は、AIにもチャットにも貼りません。

## ① 準備

- [ ] Claude の有料プラン（Pro 以上）に入っている
- [ ] Claude のデスクトップアプリを入れている（Claude Code はアプリの中の「Code」の画面で使います）
- [ ] 学習オフ（設定の Model Improvement をオフ）／追加の従量課金（usage credits）はオフ。使うなら月の上限を決める
- [ ] 送信ボタンの横のモードが「毎回確認する」ものになっている。「確認をとばす（Bypass permissions）」は選ばない

## ② 手順

**手順1**　このフォルダ（`ai-shain-kit`）を、Macは「書類」フォルダ、Windowsは「ドキュメント」フォルダに置く（今の仕事のフォルダの中には入れない）

**手順2**　Claude のデスクトップアプリを開き、「Code」の画面で、このフォルダを選ぶ。「このフォルダを信頼しますか」のような確認が出たら、自分で置いたフォルダなので「信頼する」でOK

**手順3**　Claude に次の1行を送る

```
はじめに_これをClaudeCodeに読ませる.md を読んで、枠の中の指示どおりに進めて
```

**手順4**　質問に1つずつ答える（目安30〜40分）→ 部署の候補から番号で選ぶ（最初は3つまでがおすすめ）→ 組織図が出たら完了。**新しい会話を開き直す**（部署を読み込み直すため）

**手順5**　1回動かす。【　】を自分の言葉に変えて送る

クライアントワーカー版の方は先に：お客様との契約（秘密保持）で、打ち合わせの中身をAIに入れてよいかを確かめる。分からなければ、自分で作った練習用のメモ（架空のA社）を使う。メモは `材料/案件_A社/` に入れる

```
No.2として、【選んだ部署】に【材料や、頼みたい仕事】をもとに、【作ってほしいもの】の下書きを1本作らせて。
できたら品質チェック係（review）に審査させて。
差し戻されたら、その理由をそのまま見せて。直すのはそのあとでいい。
```

**手順6**　差し戻しの理由を、自分のルールに1行足す（次から毎回効きます）

```
いまの差し戻しの理由のうち、「次からも毎回気をつけてほしいこと」を1行にまとめて、私の【部署名】の部署ファイルの「直したことの記録」に追記して。
追記する前に案を見せて、わたしが「OK」と言ったら保存して。
そのあと、部署にもう一度作り直させて、品質チェック係にかけて。
```

**手順7**　今日の流れを、自分のスキルにしておく

```
私の「AI社員づくり」のスキルに、次の手順を追記して。スキルがなければ .claude/skills/ai-shain/SKILL.md を新しく作って。新しく作るときは、先頭に name と description（「部署を増やしたい」などの呼び出す言葉の例つき）を入れて。
・部署を増やすときは、部署カタログ.md から候補を出し、わたしが選んでから、ひな形/部署ファイルのひな形.md で .claude/agents/ に作る
・作った部署は、CLAUDE.md の部署一覧と No2の役割書.md の振り分け表に必ず足す
・どの部署にも「下書きまで（送信・投稿・公開・支払いはしない）」を入れる。品質チェック係と監査役は消さない
・差し戻しの理由は、出てきた文章ではなく、部署ファイルの「直したことの記録」に1行足して直す
・ファイルを作る・書きかえる前に、中身を見せてわたしの「OK」をもらう
追記したら、どのファイルのどこに足したかを見せて。
```

## ③ 見るところ

| 見る所 | こうなっていればOK |
| --- | --- |
| `組織図.md` | 社長 → No.2 → 選んだ部署・品質チェック係・監査役 の形になっている |
| `.claude/agents/` | 選んだ部署のファイルと `review.md`・`kansa.md` がある（見えないときは「.claude/agents の中のファイルの一覧を見せて」と聞く） |
| `CLAUDE.md` | 「1. 会社のこと」にあなたの言葉が入り、「3. やってはいけないこと」が消えずに残っている |
| `できあがり/` | 手順5で作った下書きがある |
| 品質チェック係の判定 | 「合格／条件付き合格／差し戻し」のどれかで、理由と直し方が書いてある。**差し戻されたら成功です** |
| 部署ファイルの一番下 | 「直したことの記録」に1行増えている（手順6） |

## ルーティン業務（慣れてから）

最初の1週間は手で動かして、できあがりに納得してから、定期タスクを **1つずつ** 登録します。手順は `毎朝の手順/はじめに.md` を見てください。

## 止め方

- **少し止める**：Claude に「ループ/【ファイル名】/STOP を作って」と頼む（再開は「STOP を消して」）
- **ずっと止める**：アプリの定期タスクの画面で、そのタスクをオフにする
- **いま動いている途中**：停止ボタン（■）
