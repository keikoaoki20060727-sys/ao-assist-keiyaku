# Notionの準備（使わない方は飛ばしてOK）

AI社員は、フォルダの中だけで動きます。Notionは「スマホで進捗を見たい」「AIからの質問を一覧で見たい」ときの **見る場所** です。

---

## ステップ1　アカウント

`https://www.notion.com` で無料登録（メールかGoogleアカウント）。パスワードや確認コードはClaudeに貼りません。

## ステップ2　つなぐ

Claudeのデスクトップアプリ → 設定 → コネクタ → Browse connectors → Notion → Connect → Notionでログインして許可。**公式のコネクタだけ** を使います。

※ ボタンの文字はアプリの版によって違うことがあります。

## ステップ3　作る

つないだあと、Claude に次の文を送ります。

```
Notionに、次の3つのページを作りたい。作る前に、ページの名前と項目の案を見せて。わたしが「OK」と言ったら作って。
1. 「AI進捗ボード」：データベース。項目は 部署／やること／状態（未着手・作業中・社長の確認待ち・完了）／できあがりのファイル名／日付
2. 「確認リスト」：データベース。項目は 質問／どの部署から／社長の答え／状態（未回答・回答済み）
3. 「会社の全体図」：ページ。組織図.md と CLAUDE.md の「1. 会社のこと」「2. 部署一覧」を写す
お客様の本名・会社名・連絡先は、Notionにも書かない。Notionのページを消したり、共有の設定を変えたりはしない。
```

## 使い方

- 部署の仕事が終わったら「AI進捗ボードに1行足して」と頼みます
- AIからの質問は「確認リストに足して」と頼むと、スマホから見られます
- Notionに書くのも、社長の「OK」のあとです
